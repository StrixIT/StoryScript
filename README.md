# StoryScript
StoryScript is an engine to create games for the web. Games that run anywhere, online or offline, 
on any device, and work well with both mouse and touch control. You play your games while you 
build them! Your changes are shown immediately, allowing you to shape your world as you move 
through it.

StoryScript uses TypeScript, Vue and Vite and works especially well with Visual Studio Code 
and Rider, for which it has Code Snippets / Live Templates.

To get started, find examples or read the tutorials, please visit the [StoryScript Website](https://www.storyscript.nl).
